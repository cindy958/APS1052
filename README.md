## How apply this update

1) Start from the professor baseline project folder: `pet-shop-box-master/` (fresh, clean, without `node_modules/`).

2) Copy the files under `gitUpdate/pet-shop-box-master/` into their project root (overwrite files).

3) Run:
- `npm install`
- `truffle migrate --reset --network development`
- `npm run dev`

## What is included

- Smart contract changes (6 features): `contracts/Adoption.sol`
- Front-end changes: `src/index.html`, `src/js/app.js`
- Documentation: `README.md`, `SETUP.md`, `DELIVERY_CHECKLIST.md`
- `package.json` (devDependencies pinned)

## What is intentionally NOT included

- `node_modules/` (must never be committed)
- `build/` artifacts (generated by `truffle compile/migrate`)
- Ganache data, MetaMask data, IDE temp folders
